About this application

Sur-e-Syahi Shorts Uploader is a private tool used only by the owner of the Sur-e-Syahi YouTube channel. It runs on the owner's own computer and:

  • selects a couplet from public-domain poets (Mirza Ghalib, Mir Taqi Mir, Allama Iqbal and others),
  • places it on a royalty-free wallpaper with royalty-free background music,
  • renders a 15-second vertical video, and
  • uploads it to the owner's own channel through the YouTube Data API, scheduled for publishing.

Use of YouTube API Services

This application uses YouTube API Services. It requests a single permission, youtube.upload, which is used only to upload videos to the channel of the person who signs in. It does not read, modify or delete any other YouTube data.
